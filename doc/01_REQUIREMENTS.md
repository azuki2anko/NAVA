# Yamaha AV Manager 要件基準索引

版: 2.0

更新日: 2026-09-02

## 1. 正式な要件基準

Yamaha AV Managerの要件は、公開版とプライベート版で次のように構成する。

| エディション | 正式な要件 |
|---|---|
| 公開版 | [`public/01_REQUIREMENTS_PUBLIC.md`](public/01_REQUIREMENTS_PUBLIC.md) |
| プライベート版 | 公開版要件 + `.private/doc/01_REQUIREMENTS_PRIVATE.md` |

`.private/`は公開リポジトリの追跡対象外である。公開版のcloneにはプライベート要件は含まれない。

## 2. 優先順位

要件が食い違う場合は、次の順で優先する。

1. ユーザーがその時点で明示した指示
2. セキュリティ・安全要件と実機操作の確認境界
3. プライベート版ではprivate追加要件
4. 公開版要件
5. 実装ガイド、Capabilityスナップショット、旧統合要件

private追加要件は公開版の安全要件を弱めてはならない。Alexa、自宅サーバー、Windowsサービス等の対象外項目をprivate側で復活させてはならない。

## 3. 分離前要件の扱い

分離前の統合要件は `.private/doc/01_REQUIREMENTS_COMBINED_LEGACY.md` に保存する。これは要件欠落を監査するための参考資料であり、今後の正式要件ではない。

プライベート版は「公開版を縮小した別製品」ではない。公開版の全要件を満たしたうえで、個人環境固有の機能を追加する。

## 4. 機密情報

公開・privateのどちらの仕様書にも、実IPアドレス、MACアドレス、機器ID、トークン、MacroButtonの実番号、秘密鍵を記載しない。具体値はリポジトリ外の実行時設定またはprivateの安全な資格情報ストアで管理する。
